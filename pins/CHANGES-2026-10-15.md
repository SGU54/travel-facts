# pins skill v2 — 2026-10-15

Installed at `~/.claude/skills/pins/`; archive rebuilt as `pins.skill` in this folder.
The 2026-09-18 review (`astra-review-pins.md`) was applied item by item, and the
engine was tested end to end on baliforamericans with real R2 article photos
(8/8 pins pass in release mode).

| review item | what changed |
|---|---|
| A1 comparator | `compare` now requires `basis`, `left/right.unit`; a `winner` requires `verdict` + `winner_condition`. Units print at 42px under each value; the basis line prints under the grid. The big value is auto-fitted to its column on one line. |
| A2 legibility | B items 44/38 (≤4), 40/34 (5), 36/30 (6–7, `density:"tight"`); C labels 40, units 42, verdict 44. The engine measures headline lines and fails a pin over its budget ("rewrite it"), never shrinks it. |
| A3 destination | `promise` + `destination_type: article|magnet` are required; a bare domain is rejected; `SITE.magnet.promise` documents what the PDF keeps. |
| B1 proofs | Proofs are made with Pillow from the PNG bytes (236/180/600 + a contact sheet). The `file://` second page is gone. |
| B2 draft/release | `--mode release` fails closed on placeholder/missing photo, unloaded font, overflow, title budget, footer position, comparator contract; exit 1. `_report.json` records status per pin. Photos are fetched with curl, verified with Pillow, embedded as data URIs (no silent `onerror`). |
| B3 B footer | `margin:auto` restored; the engine asserts the band's bottom edge = canvas bottom. |
| C1 layout | A has `layout: photo_first | message_first`; a 3-line headline triggers a second pass with a shorter photo. |
| C2 shape | `SITE.shape` (frame double/single/none, badge diamond/circle/square, display weight/tracking/line-height); tints computed with `rgba()` from any `#hex` or `rgb()` token. |
| C3 photos | Requested at zone size × DPR from R2 (`/cdn-cgi/image/…`) or R2; a source smaller than wanted is reported as `low-res`. |
| D | "A→clicks, B→saves, C→reshares" demoted to hypotheses; "the image only decides the click" retired. |
| D5 CSV | `pins_upload.csv` lists only the pins THIS run rendered and validated, with a status column. |

Also new: template **P** (the article's own hero full-bleed under a
luminance-aware brand scrim), ported from `japanforamericans/scripts/make-pins.py`,
the fleet's first live batch; `scripts/fetch_articles.py`, which pulls a site's
published articles (slug, title, excerpt, featured_image, swamp) so the batch is
picked from what exists; `references/pins_bali_example.py` as the v2 reference
file. The Rome v1 example is kept for the R2 shape; run through the v2
engine it reports 12 contract failures and renders nothing, which is the point.

Not done, on purpose: Pinterest account strategy, cadence automation, any
publishing. The skill produces files; the owner uploads them.
