# Compose the content into readable pages

The reader follows an argument, not the build's page boundaries. Use flowing body
sections and place tables/figures with the paragraphs that introduce them.
Use fresh pages for substantial chapter openings when useful; short related sections
can continue. Neither one-page-per-item nor universal chapter breaks is required.

## Fix real defects

| Observed defect | Appropriate response |
|---|---|
| Heading stranded above a page break | Keep it with its first lines; adjust the source grouping |
| Long table forced wholly onto the next page | Allow table splitting with repeated headers and intact rows |
| Caption separated from its figure | Group them or reduce nonessential surrounding space |
| Short accidental tail | Recompose preceding blocks or simplify actual repetition |
| Tiny labels or crowded cells | Widen/wrap, increase figure height, or redesign the table |
| Meaningful section partly empty | Judge its reading purpose before changing it |
| Photo unrelated to nearby text | Move, replace, or remove that photograph |

Never hide overflow, delete an important exception, or reduce essential text to make a
page count. A larger page count can be the correct consequence of correcting the content.

## Consistent structure

Use a clear type hierarchy, a coherent spacing scale, stable table structures for comparable
data, and useful running furniture. Avoid identical repeated callout machinery on every
page. A verdict can be prose, a table conclusion, or a compact box depending on the job.

Stable IDs and generated numbering keep cross-references maintainable. A figure is emitted
once unless there is a reason to repeat it. A summary should be shorter than the reasoning
and preserve the condition that changes the recommendation.

## Inspect after rendering

Look at the full sequence for abrupt density swings and repetitive layouts, then read
every page. Check continuation pages as carefully as chapter starts. Density and photo
rhythm scripts can point to pages worth looking at; their historical thresholds are not
release gates. A correct, legible quiet page is preferable to padding.

Use quality-standard.md for acceptance and audit-release.py for publication checks.
The optional compositor passes must preserve the manuscript and readable figure size.
