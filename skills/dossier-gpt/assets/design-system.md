# Dossier design system

Use the existing destination brand or derive a restrained provisional identity.
`references/quality-standard.md` governs acceptance; `assets/print-base.css` is a
starting point. Format and reader needs can justify different settings.

## Shared hierarchy

| Role | Starting printed size | Purpose |
|---|---:|---|
| Cover title | 40–60pt | One recognizable title at thumbnail size |
| Chapter heading | 24–30pt | Find the decision |
| Subheading | 16–20pt | Scan the argument |
| Body | 11–12pt | Comfortable sustained reading |
| Table/caption/essential map label | 9–10.5pt | Read the qualification as well as the value |
| Running head and folio | 7.5–8.5pt | Secondary navigation |

Use final printed points, including SVG transforms. Three font roles suffice:
display, reading, short data labels. Real font weights and sufficient contrast matter
more than the number of fonts. Avoid all-caps tracked small type for explanations.

## Color and spacing

Choose paper, dark ink, one main accent, a secondary accent if needed, muted text,
and a pale rule/tint. White paper is an intentional option. Do not use the pale accent
for small essential text. A default, exception, or decisive table row is labeled in words;
color only reinforces the meaning.

Use a small coherent spacing scale around the body baseline. Keep figures with their
discussion and captions with their figure. Consistency is useful; mechanical uniformity
that strands a heading or crushes a table is not. Whitespace needs no minimum ink quota.

## Tables and figures

Use semantic tables, correct column counts, named units, aligned numeric columns, and
repeated headers for long tables. Column widths follow their contents: give the action
and qualification enough width, let source URLs wrap, and do not squeeze a sentence
into a narrow label column. Keep related comparisons on compatible column structures.

Use vector text and shapes for exact diagrams. A decision tree must include the same
eligibility conditions and exceptions as the prose. A schedule scale cannot retain an
old number after the table is corrected. Critical repeated labels use claim bindings.

Photographs show a verified subject and a suitable crop. Stable slot IDs identify
assets; reader-facing figure numbers follow appearance order. Generate the mapping once.
There is no mandatory photograph count or percentage.

## Common acceptance questions

Can a buyer understand the cover at thumbnail size? Can the reader find the answer
from the contents? Can they read every important condition at normal size? Do diagrams,
recaps, and the Sheet give the same action? Is each photograph truthful to its caption?
Do continuations look as carefully set as openers? Has any prose vanished after rendering?

Keep decorative production labels out of the product. Brand examples in this skill
are examples of identities, not defaults for every destination.
