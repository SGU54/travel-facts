# M2 — Adaptation: the surfaces in THIS site's voice

The skill ships no fixed widget. Every surface (band, aside, inline, sales page) is
composed FROM the site's design identity, per site. Greece's band belongs to "Come Up
For Air"; Rome's to "La Tavola". A generic widget shipped across sites has already
failed.

## The method, in order

1. **Look at the LIVE site, not the dossier.** The dossier's printed palette is the
   BOOK's identity. The site's is tokens.css + what actually renders. The proven
   failure: Greece surfaces drafted in the dossier's dark cream read as bolted-on; the
   live site is light warm-gray with a mint accent — rebuilt in that, they read native.
   Screenshot the real article page first; sample nothing from the PDF.

2. **Find the site's existing CTA grammar and ECHO it.** Every shipped site already
   sells something (an itinerary tool, a lead magnet, a featured band). That block IS
   the site's approved way of asking for a click. The guide band should read as its
   sibling: same surface treatment, same button shape, same kicker style. Greece's
   winning move: the end band echoes the dark-slate "Keep planning / Build your trip"
   block — same slate, same mint pill. The reader has already accepted that grammar.

3. **Compose each surface from tokens** — colors, faces, radii, button shapes all from
   tokens.css (or sampled from the live chrome when tokens don't cover it, then fed
   back into tokens). Never invent a new accent for the ads; the guide is the site's
   own product and wears the site's own clothes.

4. **The cover does the visual selling.** It's a real designed artifact (the dossier's
   own cover) — a thumbnail of it outperforms any badge or icon. Use the real web
   export, never a CSS stand-in in production.

5. **The not-an-ad test (screenshot judgment, every site).** Look at the rendered
   surface cold: could it be mistaken for a third-party unit? Banner grammar, alien
   accent, urgency styling → redo. It must look like the site recommending its own
   book.

## Per-surface composition notes

- **End band** — the site's dark/featured CTA treatment if one exists; cover thumb +
  kicker + name + hook + one pill. Never full-width screaming color.
- **Sticky aside** — quietest surface: card in the rail's own idiom, under the TOC,
  outline button. It reinforces; it never shouts.
- **Inline marker** — lightest of all: a keyline in the site's accent, body-width,
  reads as an editorial callout (the site already has pull-quote/note styling? echo
  it).
- **Sales page** — the site's article typography at its best; the cover large; the
  site's own button style for the buy CTA. It's a page OF the site, not a landing
  page from elsewhere.

## Quality floor

AA contrast against this site's palette; real characters not entities; keyboard focus
visible; no fake affordances; mobile: band restacks, aside drops below content, marker
stays body-width. All hard rules from travel-empire apply — this stage styles what 5c
mounts, it never changes the mounts.
