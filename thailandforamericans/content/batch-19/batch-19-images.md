# batch-19-images.md — download manifest

**10 images, in this exact order.** Save as `01.jpg` … `10.jpg` in one folder.

```
node scripts/upload-batch.mjs <images-folder> import-batch-19.json
```

**Check before saving:** landscape, ≥1600px wide, Unsplash/Pexels license, no recognizable
faces, no readable brand signage.

⚠ **This batch is medical and immigration. The register rule is stricter than usual:**
no injuries, no patients, no ambulances, no ER interiors, no distress. These are factual
articles about how systems work, not warnings. A photo that reads as alarming turns the whole
article into a scare piece and breaks the trust the writing depends on. Calm, empty, daylight.

**macOS:** if the uploader reports double the count, run `dot_clean .` in the folder.
