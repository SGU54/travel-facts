```
node scripts/upload-batch.mjs <images-folder> import-batch-20.json
```

**Check before saving:** landscape, ≥1600px wide, Unsplash/Pexels license, no recognizable
faces, **no readable airline or airport branding** (this batch is transport, so logos are the
main risk — tail liveries, carrier signage, station name boards).
